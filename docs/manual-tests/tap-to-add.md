# Tap phones to add (ACC-13)

Two phones with the dev build, both signed in with different accounts that are **not** friends yet. Best with one iPhone 11 or later on each side (UWB); steps 7–8 cover phones without it.

| # | Who | Step | Expected | Result |
|---|---|---|---|---|
| 1 | Both | Open Nudge to Friends. | First time: "find devices on your local network" prompt. Allow. | |
| 2 | Both | Slowly bring the tops of the phones together. | First time: "find and interact with nearby devices" prompt. Allow. Then a lavender glow grows at the top edge and the app leans back as the phones get closer. | |
| 3 | Both | Touch the tops. | Heavy haptic, the glow blooms and a wave wipes the screen, "Adding friend…" with ripples. | |
| 4 | Both | Wait. | Within ~1 s: success haptic; their avatar drops from the top, yours rises from the bottom, they meet with a burst; "You and Sam are friends". | |
| 5 | Either | Tap Say hi. | Opens the thread with them. The other person shows in Friends on both phones. | |
| 6 | Both | Touch the phones again. | Nothing happens: no glow, no animation, no request. | |
| 7 | Both | (Non-UWB phone or UWB denied) Hold phones still, then knock the tops together once. | Same as 3–4. | |
| 8 | One | Knock your phone on the table while the other phone sits still. | Nothing happens. | |
| 9 | One | Open Nudge on only one phone and touch. | Nothing happens (both must have the app open). | |
| 10 | Either | Block the other, unblock, remove friend; touch again. | Blocked: nothing / "Didn't catch that". After unblocking and removing: adds again. | |
| 11 | Either | Start a call, then touch phones. | Nothing: tap is off during calls. | |
